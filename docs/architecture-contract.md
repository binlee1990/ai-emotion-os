## 1. Purpose

- **目标**：把调研建立的知识基础（事件类型学 §2、情绪体系 §3、强度因子 §4、领域机制 §5、工程综合 §6）实现为一个可计算、可测试的情绪引擎 Python 库 `emotion_os`，用调研场景验证「事件→情绪」映射的可用性（调研附录建议的原型验证）。
- **成功标准**：见任务合同 Success criteria；核心可观察判据是场景测试——引擎对调研 §6.2 主对照表取样的场景输出与调研预测一致。
- **不可牺牲项**：
  1. **评价先行**（§6.3.1）：情绪由「事件×主体目标/标准」的评价产生，任何地方不得退化为「事件关键词→情绪」直查；
  2. **双表示**（§6.3.2）：类别（可读、中文可分级）与 4D 维度（愉悦/唤醒/支配/意外性，§2.2 Fontaine）并存，类别是软激活而非排他标签（§3.1 建构论证据）；
  3. **强度独立乘法结构**（§6.3.3）：事件因子×个体因子×状态因子；
  4. **理论不可知**（§7.1）：不把任何单一理论硬编码为真值，映射表可替换。

## 3. 参考系统与可迁移模式（S3）

来源均为调研 §6.1 引用的公开学术系统（published academic systems，观察其机制而非复制代码）：

## 4. 选定架构（S4）

### 4.1 管线与数据流（调研 §6.1）

```
Event(schema: §2.5 11大类 + SEC 子维度字段)
  → Appraiser  评价器: SEC 四检查 → AppraisalResult；OCC 三分支判定
  → Generator  情绪生成: 家族评价器(§6.2 映射) → 类别激活集
                原型 4D 混合 → 维度通道; 强度乘数 → intensity
  → Dynamics   动力学: 情绪层(onset/peak/decay, 惯性, 习惯化/敏感化)
                心情层(慢速EMA) ; 唤醒残余(兴奋转移 §1.5.2) ; 峰终记忆评分
  → Regulation 调节: 重评(改评价向量) / 抑制(掩表达留体验+代价) ; 调节力=人格×状态
  → Expression 表达: 中文分级词表 + 4D 坐标双通道输出; 混合情绪可读描述
```

### 4.2 模块与 I/O 契约

| 模块（包） | 输入 | 输出 | 依赖 |
|---|---|---|---|
| `emotion_os.core` | — | `Event`、`AgentProfile`（目标/标准/BigFive/调节力/敏感化史）、`EmotionEpisode`、`AffectState`（三层） | 无 |
| `emotion_os.appraiser` | `Event × AgentProfile` | `AppraisalResult`（SEC 维度 + 归因 + OCC 分支 + 安全框架判定） | core |
| `emotion_os.generation` | `AppraisalResult × AgentProfile × AffectState` | `list[EmotionEpisode]`（类别 id、激活、4D、强度、行动倾向、wanting/liking 双通道标记 §6.3.6） | core |
| `emotion_os.dynamics` | `episodes × AffectState × dt` | 更新后的 `AffectState`（衰减/惯性/心情 EMA/习惯化/峰终记忆值） | core |
| `emotion_os.regulation` | `AppraisalResult/AffectState × 策略` | 调节后的评价/状态（重评先于生成，抑制后于生成） | core, appraiser |
| `emotion_os.expression` | `AffectState` | `ExpressionOutput`（top-k 类别中文词+强度档、4D 聚合坐标、混合描述） | core |
| `emotion_os.engine` | 全部 | `EmotionEngine.process(event, dt)` 单入口编排 | 全部 |

规则：上下游只经由 dataclass 契约通信；类别注册表（id/中文/英文/家族/4D 原型/行动倾向）是 generation 与 expression 的共享单一来源，放 `emotion_os/generation/catalog.py`。

### 4.3 关键数据结构（决策级，字段实现见代码 docstring）

- `Event`：类别（A–K 枚举）、指向（谁受影响/谁造成/故意性）、目标影响 `dict[goal_id, Δ]`、期望违背、概率、紧迫、可控性提示、可逆性、新异性、内在愉悦度、道德信息（违范/美德×严重度）、社会比较信息（方向/应得感/好恶）、联结变化（骤增/断裂/渐变）、审美信息（巨大感/美/卓越）、安全框架 0–1、虚构性 0–1、时间指向。
- `AppraisalResult`：SEC① 新异性/内在愉悦/目标相关；SEC② 归因(对象+故意)/结果概率/期望背离/促进-阻碍/紧迫；SEC③ 控制/力量/调整；SEC④ 内/外标准；派生 `occ_branch`（consequences/prospects/agency/attraction/fortunes-of-others 复合判定）。
- 类别目录：≥50 类别（v0.1 实现 82 条，v0.2 增至 88 条），覆盖调研 §3.3 各情绪家族（混合情绪不设独立家族，由软激活并存表达，如「又好气又好笑」）+ 9 个中文特有词（委屈/解气/爽/憋屈/心疼/意难平/破防/麻了/磕到了），每条含 4D 原型与强度分级锚点。

## 5. 领域规则（S5）

规则全文（含正例/反例/检查方式）：[grammar/appraisal-grammar.yaml](grammar/appraisal-grammar.yaml)，机检 G3。规则与缺陷的对应（违反→可观察缺陷）：

| rule_id | 规则 | 违反的可观察缺陷 |
|---|---|---|
| R-APP-01 | 愤怒=高相关+他人故意+阻碍+高控制（§2.1） | 同型事件低控制时误报愤怒（应为恐惧/悲伤，§2.5 C） |
| R-APP-02 | 解气=先前对该违规者的义愤+其受罚（§2.5 E，de Quervain 2004；受罚方经 `justice_target` 与记账匹配） | 无先前义愤也产生解气；罚错对象产生解气而非内疚 |
| R-APP-03 | 羡慕按应得感×控制分流良性/恶意（§3.3 van de Ven；恶意记账跨事件提升对该对象的幸灾乐祸） | 高应得上行比较误判为恶意羡慕（应为上进动机） |
| R-APP-04 | 安全框架内恐惧享受呈倒 U（§5.1） | 恐怖场景输出纯恐惧无享受，或高强度仍线性享受 |
| R-APP-05 | kama muta=共享关系骤增触发、短时程（§1.5.8） | 渐进亲密也触发感动（应为温情）；感动持续数小时 |
| R-INT-01 | 强度乘法结构，相关性为零→情绪为零（§1.1） | 与主体无关的事件产生情绪 |
| R-INT-02 | 损失厌恶不对称（§4.1） | 同幅度得失情绪强度对称，高估乐/低估痛 |
| R-DYN-01 | 情绪分钟级衰减、心情慢速 EMA（§4.4） | 单层状态：哀伤永不过期或心情逐事件震荡 |
| R-DYN-02 | 记忆评分≈峰+终，时长忽视（§1.5.10） | 时长加权评分低估 BE 结局的意难平 |
| R-EXP-01 | 表达=类别词+4D 双通道（§6.3.2） | 无法表达「又好气又好笑」类混合（§3.4） |

## 8. 未决项与接续点

- 自然语言→`Event` 适配器（LLM 结构化输出）未做——v0.1 输入为结构化事件，是刻意的接口边界。
- 领域强度量化参数：倒 U 顶点 v0.3 已由 OSF 数据实证标定（见下方参数标定状态）；习惯化速率仍缺单一实证常数，v0.1 取可调常数并在代码标注「待标定」。
- 中文词表正式度/场合分级（v0.6 已做，表达层「强度×语域」双维完整）：单语域轴三档 formal（书面/对外正式）/ neutral（默认=v0.5 行为不变）/ colloquial（口语/对内私下），`Expressor.describe(register=...)` 与 `graded_word(..., register=...)` 透传，未覆盖类别显式回退 neutral。覆盖 30 条梯（17 formal + 13 colloquial，28 个去重类别，「语域差异显著+高频」；formal 避口语/网络语、colloquial 避书面成语腔；复审后补 fear/dread formal 梯消除「发怵」口语标记词经回退泄漏进 formal 场合的不自洽）。**标注性质**：正式度判定为语言常识自设，无语言学实证——2026-11-09 检索（google/jina 中文）未找到汉语情绪词语域/正式度分级的规范研究（AANC 为年龄差异维度、极性词库无正式度轴）；调研附录「需专门语言学补充调研」仍成立，当前为工程近似（lexicon.py docstring 同款声明）。
- wanting/liking 双通道 v0.1 只做类别级标记（§6.3.6），不建独立动机环路。
- v0.2 候选（复审 P2 遗留）：调节力并入状态项（v0.2 已实现）；下行比较「优越/安慰」（v0.2 已实现）；安全框架平滑过渡（v0.2 已实现）；wanting/liking 独立动机环路（v0.2 以双池+「上头」实现）。

- **来源勘误（对照调研.md）**：Rozin 等「良性受虐」一文年份为 **2013**（调研写作 2023）；Redelmeier 2003 结肠镜研究发表于 ***Pain*** 104:187-194（调研来源表已正确，§1.5.10 行文未标期刊）。
